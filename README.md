# SupportCS

> AI가 상담원을 보조하는 멀티테넌트 B2B 고객지원(CS) 플랫폼

## 무엇을 만드는가

여러 회사(테넌트)가 가입해서 자기 고객의 문의를 관리하는 CS 플랫폼입니다.
상담은 **사람(상담원)이 주도**하고, **AI는 상담원의 일을 덜어주는 보조** 역할을 합니다.

- 문의가 들어오면 AI가 **분류·요약**해서 상담원이 빠르게 파악할 수 있게 합니다
- AI가 **관련 정보(주문 내역, 이전 문의 등)를 미리 조회**해서 보여줍니다
- AI가 **답변 초안과 처리 방법(환불, 상태 변경 등)을 제안**하고, 상담원이 확인 후 실행합니다
- 모든 과정은 **기록**으로 남습니다

AI를 떼어내도 CS 시스템(테넌트, 권한, 티켓, 채팅)은 그대로 동작합니다.

## 전체 흐름

```
[고객 문의]
    │
    ▼
[티켓 생성]
    │
    ▼
[AI 보조] ── 분류 · 요약 · 관련 정보 조회 · 답변 초안 · 처리 제안
    │
    ▼
[상담원 처리]
    │
    ├─ 답변 ────────▶ AI 초안 확인 → 수정 → 발송
    │
    └─ 업무 처리 ────▶ AI 제안 확인 → 승인하면 실행 (환불, 상태 변경 등)

모든 단계 ─────────────▶ [기록 (누가, 무엇을, 언제)]
```

**AI는 혼자 실행하지 않습니다.** 고객에게 나가는 답변과 실제 업무 처리는 항상 상담원이 확인한 후에 이루어집니다.

## 서비스 구성

| 서비스 | 역할 | 흐름에서의 위치 |
|---|---|---|
| API Gateway | 진입점, 인증 확인 | 문의 접수 |
| Auth/Tenant | 회사(테넌트)·멤버·권한 관리 | 모든 단계의 권한 확인 |
| Ticket | 티켓, 실시간 채팅, 상담원 배정 | 티켓 생성, 상담원 처리 |
| AI Assistant | 분류, 요약, 초안 작성, 처리 방법 제안 | AI 보조 |
| Tool Adapter | AI의 정보 조회, 상담원이 승인한 처리 실행 | 관련 정보 조회, 업무 처리 |
| Audit | 사람과 AI의 모든 행동 기록 | 기록 |

## 데모 시나리오

1. 고객이 채팅으로 "주문 취소하고 환불해주세요" 문의
2. 티켓이 생성되고, AI가 "환불 요청 / 보통 우선순위"로 분류하고 내용을 요약
3. AI가 주문 내역을 조회해서 "배송 전 주문, 환불 가능"이라고 상담원 화면에 표시
4. AI가 답변 초안과 "주문 취소 + 환불" 처리를 제안
5. 상담원이 내용을 확인하고 승인 버튼 클릭 → 환불 실행, 답변 발송
6. 대시보드에서 AI 초안 채택률, 상담원 평균 처리 시간 확인
