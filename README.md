# SupportCS

> AI 에이전트가 결합된 멀티테넌트 B2B 고객지원(CS) 플랫폼

## 무엇을 만드는가

여러 회사(테넌트)가 가입해서 자기 고객의 문의를 관리하는 CS 플랫폼입니다.
Zendesk, Intercom 같은 구조에 **AI 에이전트**를 결합했습니다.

- AI가 고객 문의에 먼저 응대하고, 필요하면 **실제 업무(주문 조회, 환불 등)까지 처리**합니다
- 위험한 작업은 **관리자 승인 후** 실행합니다
- AI가 해결할 수 없으면 **상담원에게 연결**합니다
- 모든 과정은 **기록**으로 남습니다

AI를 떼어내도 CS 시스템(테넌트, 권한, 티켓, 채팅)은 그대로 동작합니다.

## 전체 흐름

```
[고객 문의]
    │
    ▼
[AI 응대]
    │  필요하면 시스템 조회 (주문, 고객정보 등)
    │
    ├─ 해결 가능 ──────────▶ [AI가 처리]
    │                          │
    │                          ├─ 소액/저위험 → 바로 실행
    │                          └─ 고액/고위험 → 관리자 승인 후 실행
    │
    └─ 해결 불가 ──────────▶ [티켓 생성 → 상담원 연결]

모든 단계 ─────────────────▶ [기록 (누가, 무엇을, 언제)]
```

## 서비스 구성

| 서비스 | 역할 | 흐름에서의 위치 |
|---|---|---|
| API Gateway | 진입점, 인증 확인 | 문의 접수 |
| Auth/Tenant | 회사(테넌트)·멤버·권한 관리 | 모든 단계의 권한 확인 |
| Ticket | 티켓, 실시간 채팅, 상담원 배정 | 문의 접수, 상담원 연결 |
| Agent Orchestrator | AI 응대 (판단하고 필요한 도구 호출) | AI 응대 |
| Tool Adapter | AI가 시스템을 조회·처리하는 통로, 승인 관리 | 시스템 조회·처리, 승인 |
| Audit | 사람과 AI의 모든 행동 기록 | 기록 |

## 데모 시나리오

1. 고객이 채팅으로 "주문 취소하고 환불해주세요" 문의
2. AI가 주문을 조회하고, 소액이면 바로 환불
3. 고액이면 관리자가 AI의 판단 근거를 보고 승인
4. 고객이 상담원 연결을 원하거나 AI가 답하기 어려우면 티켓을 만들어 상담원에게 연결
5. 대시보드에서 AI 자동 처리 비율, 상담원 연결 비율 확인
